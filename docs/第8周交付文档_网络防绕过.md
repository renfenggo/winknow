### 3.2 代理守卫流程（ProxyGuard）

```
启动 → Timer 20s 周期
         │
         ▼
    读取 HKCU 快照
    读取 HKLM 快照
         │
    ┌────┴────┐
    │IsTampered?│
    └────┬────┘
         │ 是
         ▼
    ProxyTampered 事件触发
    RestoreInternal:
      ProxyEnable = 0
      删除 ProxyServer
      删除/恢复 AutoConfigURL
         │
         ▼
    回到合规状态
```

**策略判定规则**（`Allowed=false` 时）：
- `ProxyEnable != 0` → 篡改
- `ProxyServer` 非空 → 篡改
- `AutoConfigURL` 非空且 PAC 不允许 → 篡改
- `AutoConfigURL` 与策略允许的 URL 不匹配 → 篡改

### 3.3 PAC 保护流程（PacProtector）

```
Initialize(autoConfigUrl)
  → 解析 file:/// 为本地路径
  → 计算基准 SHA256
         │
StartMonitoring()
  → FileSystemWatcher 监控
         │
    ┌────┴────┐
    │文件变更? │
    └────┬────┘
         │ 是
         ▼
    PacTampered 事件
    VerifyIntegrity():
      重算 SHA256
      对比基准
         │
    ┌────┴────┐
    │Hash 一致?│
    └────┬────┘
         │ 否
         ▼
    Restore(backupContent):
      写回基准内容
      校验恢复后 Hash
```

### 3.4 失败模式决策（NetworkFailMode）

| 场景 | strict 模式 | lenient 模式 |
|------|------------|-------------|
| 代理服务故障 | ❌ 阻断（不静默放行） | ✅ 放行（保可用性） |
| 策略组件异常 | ❌ 阻断 | ✅ 放行 |
| 默认值 | ✅ strict（安全优先） | — |

**验收达成**：`ShouldAllowOnFailure(FailMode.Strict)` 返回 `false`，代理崩溃时不会静默全部放行。

### 3.5 浏览器企业策略注册表路径

| 浏览器 | 注册表路径 | 策略值 |
|--------|-----------|--------|
| Chrome | `HKLM\SOFTWARE\Policies\Google\Chrome` | `ProxyMode=2`、`DnsOverHttpsMode=off`、`BuiltInDnsClientEnabled=0` |
| Edge | `HKLM\SOFTWARE\Policies\Microsoft\Edge` | 同上 |

### 3.6 VPN 检测三维度

| 维度 | 检测方式 | 默认黑名单示例 |
|------|----------|---------------|
| 进程 | `Process.GetProcesses` 匹配进程名 | openvpn、nordvpn、expressvpn、v2ray、clash、shadowsocks、xray、sing-box 等 |
| 服务 | `ServiceController.GetServices` 匹配运行中服务 | 策略 `BlockedServices` 列表 |
| 虚拟网卡 | `NetworkInterface.GetAllNetworkInterfaces` 关键词匹配 | tap、tun、vpn、wireguard、openvpn、hamachi、zerotier 等 |

### 6.1 本次实现细节

1. **策略模型先行**：先扩展 `PolicyFile.cs` 新增 6 个配置段（Dns/BrowserPolicy/VpnDetection/WebsiteHealth 等），所有组件通过构造函数注入策略，实现策略与实现解耦。

2. **ProxyGuard 双 hive 监控**：同时监控 HKCU（用户级）和 HKLM（系统级）代理设置，防止学生从任一层面篡改。20 秒周期由 `Timer` 实现，`CheckAndRestore` 也可手动触发。

3. **PacProtector file:// 协议解析**：支持 `file:///C:/path/proxy.pac` 和直接路径，`http://` URL 不支持本地监控（返回 `PathNotFound`），符合教学场景 PAC 部署在本地 的实际。

4. **DnsMonitor 默认黑名单**：即使策略未配置 `BlockedServers`，也默认检测 8 个公共 DNS（Google/Cloudflare/Quad9/OpenDNS），确保基线安全。

5. **BrowserPolicyEnforcer 注册表推送**：通过 HKLM `SOFTWARE\Policies\Google\Chrome` 和 `SOFTWARE\Policies\Microsoft\Edge` 推送企业策略，学生无法在浏览器设置中覆盖（企业策略优先级高于用户设置）。

6. **VpnTunDetector 三维度**：进程（20+ 黑名单，含 v2ray/clash 等国产工具）、服务、虚拟网卡，覆盖常见 VPN 绕过手段。

7. **NetworkFailMode 默认 strict**：策略文件 `FailMode=strict`，代理故障时阻断而非放行，符合"安全优先"原则。

8. **WebsiteHealthChecker 自签证书容错**：`ServerCertificateCustomValidationCallback` 允许自签证书，适应教学环境可能使用的自签 HTTPS。
