# Winknow V7.0 部署检查清单

> **版本**：V7.0 软件与设备安全增强版
> **适用环境**：编程课堂管控终端
> **说明**：本清单覆盖安装前、安装后与定期复检三个阶段。所有检查项默认状态为"未验证"，完成核验后方可标记通过。无法自动检测的项目必须人工核验，未知状态绝不标记为安全。

---

## 一、系统与环境前提

| 检查项 | 要求 | 验证方式 | 状态 |
|--------|------|----------|------|
| 操作系统 | Windows 10 Pro 22H2+ 或 Windows 11 Pro | `winver` / `Get-ComputerInfo` | [ ] 未验证 |
| .NET 运行时 | .NET Desktop Runtime 8.0.x (LTS) | `dotnet --list-runtimes` | [ ] 未验证 |
| 运行身份 | 学生为标准用户，非管理员 | `whoami /groups` 确认无 Administrators | [ ] 未验证 |
| 管理员账号 | 独立管理员账号，密码带盐慢 Hash | 维护模式入口验证 | [ ] 未验证 |
| 磁盘空间 | 系统盘剩余 ≥ 2 GB | `Get-PSDrive C` | [ ] 未验证 |

---

## 二、固件与启动安全（安装前核验）

> V7.0 不使用 BitLocker，设备启动安全依赖固件配置 + 物理管理。

| 检查项 | 要求 | 验证方式 | 状态 |
|--------|------|----------|------|
| Secure Boot | 必须启用（OFF = High Risk，拒绝部署） | `Confirm-SecureBootUEFI` | [ ] 未验证 |
| BIOS/UEFI 管理员密码 | 已设置 | 人工核验（重启进入固件设置） | [ ] 未验证 |
| USB/External Boot | 禁止 | 人工核验固件菜单 | [ ] 未验证 |
| PXE/Network Boot | 禁止 | 人工核验固件菜单 | [ ] 未验证 |
| 一次性 Boot Menu | 禁用或设密码 | 人工核验固件菜单 | [ ] 未验证 |
| Boot Order | 仅系统盘优先 | 人工核验固件菜单 | [ ] 未验证 |
| 启动模式 | UEFI（非 Legacy/CSM） | `bcdedit /enum firmware` | [ ] 未验证 |

## 六、边界声明（V7.0 不实现的能力）

- **不使用 BitLocker**：成功离线访问后磁盘可被修改，依赖禁止外部启动 + Secure Boot + 物理管理。
- **不使用 AppLocker**：软件管控依赖 WMI 监听 + 周期扫描，不依赖系统 AppLocker。
- **不拦截 Ctrl+Alt+Del (SAS)**：安全依赖标准用户权限与 ACL，不尝试拦截 SAS。
- **不以进程名为唯一放行依据**：路径、签名、Hash、用户、父进程共同参与判断。

## 七、核验记录

每次部署或复检须留存以下信息：

- 设备标识（DeviceId / 序列号 / 品牌 / 型号）
- 核验人、核验时间、核验结果
- 固件版本（更新后旧记录自动失效）
- 未通过项及整改说明
- 人工核验项的证据（照片/截图）
