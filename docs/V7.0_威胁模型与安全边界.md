# V7.0 威胁模型与安全边界

> 版本：V7.0 | 状态：第1周交付物 | 基线：.NET 8.0 LTS、net8.0-windows | 日期：2026-08-28

## 一、攻击者等级（A1-A5）

| 等级 | 画像 | 能力上限 | V7.0 防护目标 |
|------|------|---------|--------------|
| A1 | 普通学生 | GUI 操作、快捷键、运行程序 | 完全阻止 |
| A2 | 技术学生 | 自写程序、Win32 API、用户层注册表 | 完全阻止 |
| A3 | 进阶学生 | 进程注入、DLL 劫持、调试器、Hook | 阻止+检测+审计 |
| A4 | 物理访问 | U 盘启动、PE、拆卸硬盘 | 提高成本，不承诺阻止 |
| A5 | 国家级 | 0day、内核漏洞、固件级 | 不在 V7.0 范围 |

## 二、安全边界

- **在线防护（A1-A3）**：承诺。标准用户权限 + 软件管控 + 服务加固。
- **离线磁盘机密性（A4）**：不承诺。不使用 BitLocker。
- **SAS 拦截**：不尝试。不拦截 Ctrl+Alt+Del，不劫持 GINA/Credential Provider。
- **内核防护（A5）**：不在范围。

### SAS 处理

V7.0 不拦截 Ctrl+Alt+Del。安全依赖：标准用户权限 + 任务管理器策略 + Service DACL + 文件 ACL + 注册表 ACL + 软件管控 + 安全 IPC。

### A4 离线防护链

BIOS/UEFI 密码 + 关闭 USB/External/PXE Boot + 限制 Boot Menu/Order + Secure Boot（必须开启）+ 物理管理。

**Secure Boot**：OFF → High Risk → 不能通过验收；UNKNOWN → 不得默认 PASS。

## 三、部署前提

- OS：Windows 10 Pro 22H2+ 或 Windows 11 Pro，x64，UEFI
- 学生账户：标准用户（非管理员）
- Secure Boot：必须开启
- 不使用：BitLocker、AppLocker、WFP/驱动、SAS 拦截
