# ADR-002：V7 网络能力边界与失败模式

| 项 | 内容 |
|---|---|

| 日期 | 2026-09-02 |

| 关联任务 | PR-09（浏览器与用户 Hive 网络策略）、阶段 5 全部任务 |
| 关联问题 | B-08（网站白名单未接入真实流量） |

## 背景

当前 `WebsiteFilter` 等域名判断类存在，但主服务从未调用其处理真实流量；无 WFP、防火墙规则、受控代理或浏览器扩展，"网站白名单"实际不构成阻断（说明书 B-08、5.3 节）。全系统域名级白名单需要内核 WFP Callout Driver（驱动签名、HLK 测试，预估 3～6 周额外开发），超出 V7 范围。

## 决策

### TD-03 网络能力边界

V7 采用**受管浏览器策略**交付，不声称"全系统域名白名单"：

1. Chrome/Edge 企业策略 `URLBlocklist=["*"]` + `URLAllowlist=<课堂白名单>`（主域、子域、登录、API、CDN、提交端点全覆盖）。
2. 禁止浏览器自定义代理、DoH/Secure DNS 和非授权扩展。
3. 其他浏览器、VPN、代理工具、脚本解释器由**应用白名单**（进程管控）限制运行。
4. 对系统代理、PAC、DNS、虚拟网卡做检测、恢复与审计。
5. UI/产品文档明确承诺边界：**V7 保证受管浏览器内的课堂访问范围，不承诺任意第三方进程的域名级过滤**。

若业务坚持全系统域名白名单：在本 ADR 处设置架构停止点，单独立项 WFP/受控网关（+3～6 周及驱动签名/兼容性成本），不得用 hosts 文件或注册表轮询冒充。

### TD-07 失败模式

1. 安全组件无法初始化 → 进入**可观察的 Degraded 状态**并写 Windows Event Log，不允许静默"全部放行"。
2. 策略损坏、代理检测失败、更新失败同样进入 Degraded 并告警，不静默降级为无管控。
3. 不允许未经验证的无限阻断导致教学电脑不可恢复：必须始终保留**双因子保护的本地维护通道**（密码+TOTP/恢复码）作为最终恢复手段。
4. 断网 fail-closed 语义：授权不可达时进入离线宽限，宽限结束锁屏，但**不关闭核心管控服务**。

## 理由

- 企业浏览器策略是 Windows 原生受支持机制，无需驱动即可实现高覆盖的课堂浏览管控，配合进程白名单封杀替代客户端后，剩余绕过面（自带设备/手机热点）属于机房物理管理范畴。
- fail-closed 与"可恢复"并存：课堂场景下"锁死无法恢复"与"静默放行"都是不可接受的极端。

## 后果

- 产品宣传、README、AdminUI 文案必须与该边界一致（PR-09 交付物含文档更新）。
- 网站包发布前须做业务流程级健康验证（登录/提交/静态资源），仅 HTTP 状态码可达不算通过。

## 被否决的替代方案

- hosts 文件+轮询注册表恢复：无法覆盖 DNS over HTTPS、非浏览器客户端与直连 IP，属虚假承诺。
- WFP 内核驱动：成本与签名/兼容负担超出 V7 立项，留待单独立项。
