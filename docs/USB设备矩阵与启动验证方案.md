# USB 设备矩阵与启动尝试验证方案

> V7.0 第 12 周交付 | 配套代码：[UsbDeviceClassifier.cs](file:///c:/Users/rr/Documents/trae_projects/winknow/src/Winknow.DeviceSecurity/UsbDeviceClassifier.cs)、[UsbStorageController.cs](file:///c:/Users/rr/Documents/trae_projects/winknow/src/Winknow.DeviceSecurity/UsbStorageController.cs)
> 目的：验收"U 盘/移动硬盘不能作为普通存储使用；键盘鼠标正常；禁止外部启动后 USB PE 启动失败"

---

## 1. USB 设备矩阵（Windows 内行为）

管控原理：`UsbStorageController` 写注册表 `USBSTOR.Start=4`（大容量存储驱动禁用）+ `RemovableStorage.DenyAll=1`。**仅影响 USB Mass Storage 类（0x08）**；HID/摄像头/音频等走独立驱动类不受影响。

| 设备 | USB 类码 | 预期行为（Winknow 运行中） | 验收结论 |
|------|----------|------------------------------|----------|
| U 盘（含 USB3.0） | 0x08 | 无盘符，资源管理器不可见，不可作普通存储 | ✅ 禁用 |
| 移动硬盘（2.5"/3.5"） | 0x08 | 同上 | ✅ 禁用 |
| SD 读卡器（USB 型） | 0x08 | 同上 | ✅ 禁用 |
| USB 键盘 | 0x03 | 输入正常 | ✅ 正常 |
| USB 鼠标 | 0x03 | 移动点击正常 | ✅ 正常 |
| 数位板（教学用） | 0x03 | 正常 | ✅ 正常 |
| USB 摄像头（监考/直播课） | 0x0E | 正常 | ✅ 正常 |
| USB 耳机/声卡 | 0x01 | 正常 | ✅ 正常 |
| USB 打印机 | 0x07 | 正常 | ✅ 正常 |
| USB 扩展坞（含存储功能） | 0x09+0x08 | 带存储口的坞其存储被禁；键鼠口正常 | ✅ 混合按类 |
| USB 网卡（RTL8152 等） | 0x02 | 正常（有线教室常见） | ✅ 正常 |
| 开发板（Arduino/串口） | 0x02/0xFF | 正常（编程课必需） | ✅ 正常 |
| USB Hub | 0x09 | 拓扑正常，下游存储仍被禁 | ✅ 正常 |

**设计要点**：存储判定必须明确匹配类码 0x08——未知设备（0x00/0xFF）默认放行，防误伤教学外设；潜在风险由进程管控与审计日志兜底（威胁模型 A2 及以下层级）。

## 2. Windows 内验证步骤（每类设备 2 分钟）

1. **U 盘/移动硬盘**：插入 → 资源管理器无新盘符；`diskmgmt.msc` 磁盘管理中该盘显示"不可读/无媒体"或不列出 → **通过**；
2. **键鼠**：拔插各一次 → 输入无中断（包括开机冷启动阶段 HID 驱动不受影响） → **通过**；
3. **摄像头/音频**：相机应用/录音测试 → **通过**；
4. **扩展坞**：键鼠口正常 + 存储口插入 U 盘仍被禁 → **通过**。

## 3. 启动尝试验证（外部启动防线，需重启）

> 前置：BIOS 七项加固已完成（A6）；每台设备验收时执行一轮并记录。

### 3.1 USB PE 启动尝试

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 制作标准 WinPE/微 PE 启动 U 盘（模拟 A3 攻击者工具） | — |
| 2 | 插入目标机 USB 口，重启 | — |
| 3 | 开机按 F12/F9/F8（品牌启动菜单热键） | **Boot Menu 已禁用：热键无响应** |
| 4 | 强制进入 BIOS 尝试改启动顺序 | **无管理员密码无法修改** |
| 5 | 若机器历史上曾配置过 USB 启动项，观察 Boot Order | USB 项不在列表（已被排除） |
| 6 | 结论 | **任何路径都无法从 USB 引导 → 通过** |

### 3.2 移动硬盘启动尝试

同 3.1（移动硬盘 PE 与 U 盘 PE 判定一致，BIOS 层同为 USB Storage Boot 禁用）。

### 3.3 PXE 网络启动尝试

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 机房 DHCP 环境正常，目标机重启 | — |
| 2 | 观察启动过程 PXE 提示 | **无 PXE/E4x/E5x 报错提示（网络栈已禁用）** |
| 3 | 尝试 F12 网络启动 | Boot Menu 禁用无响应 |
| 4 | 结论 | **无法进入网络引导 → 通过** |

### 3.4 一次性 Boot Menu（验收项）

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 开机连按品牌热键（联想 F12 / 戴尔 F12 / 惠普 F9 / 华硕 F8） | **无启动菜单出现** |
| 2 | 若菜单出现：尝试选 USB/网卡项 | 记录为**不通过**，按矩阵对应品牌项整改后复测 |
| 3 | 结论 | **一次性菜单不可用 → 通过** |

## 4. 与软件防线的衔接

BIOS 层防线（本方案）被绕过的残余场景——如 BIOS 密码泄露、物理拆盘——由后续层兜底：

- 进程管控：PE 环境不加载 Winknow，但拆盘挂载场景中学生可执行程序在正常系统内仍受白名单管控；
- 审计：任何绕过尝试在恢复 Windows 后可从日志/事件锚点追溯；
- 剩余风险量化见《BitLocker剩余风险说明.md》。
