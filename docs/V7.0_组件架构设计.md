# V7.0 组件架构设计

> 版本：V7.0 | 状态：第1周交付物 | 基线：.NET 8.0 LTS、net8.0-windows | 日期：2026-08-28

## 一、组件清单

| 组件 | 类型 | 运行身份 | 职责 |
|------|------|---------|------|
| ControlService | Windows Service | LocalSystem | 核心管控、策略执行、IPC 服务端 |
| GuardService | Windows Service | LocalSystem | 守护 ControlService |
| SessionAgent | WinExe | 学生用户 | 会话内交互、键盘钩子 |
| AdminUI | WPF | 管理员(UAC) | 策略下发、设备核验 |
| TrustedUpdater | Console | LocalSystem | 签名更新、A/B 部署 |
| RecoveryTool | Console | 管理员/PE | 离线授权、紧急恢复 |

## 三、运行身份设计

- **LocalSystem**：ControlService、GuardService、TrustedUpdater（需枚举所有会话进程、终止进程、修改 ACL）
- **学生用户**：SessionAgent（会话内运行，不需要管理员权限）
- **管理员**：AdminUI、RecoveryTool（需修改系统配置）

### 敏感数据规范

- 禁止长期保存密码 string
- byte[] 使用后立即 `CryptographicOperations.ZeroMemory()`
- 持久化密钥使用 DPAPI/HSM
- 不依赖 SecureString

## 四、启动流程状态机

### 系统启动
SCM → ControlService(Automatic) → 加载配置/策略/WMI 监听/全量扫描/Named Pipe → SCM → GuardService(Automatic) → 启动监控循环

### 用户登录
ControlService 接收 WTS_SESSION_LOGON → 获取会话 ID/用户 SID → 校验学生用户 → CreateProcessAsUser 启动 SessionAgent → 下发策略

### 用户注销
ControlService 接收 WTS_SESSION_LOGOFF → 向 SessionAgent 发送退出信号 → SessionAgent 卸载钩子/关闭 IPC/退出

### 服务停止
RecoveryTool 维护模式 → ControlService 暂停监听 → 停止 → GuardService 检查维护标志 → 维护 ON 不重启 / 维护 OFF 重启

### 更新流程
TrustedUpdater 验证签名 → A/B 部署 → 重启 → 健康检查 → 异常自动回滚

### 异常恢复
ControlService 异常终止 → GuardService 检测 → 立即重启 → 重新加载策略/监听/连接 Agent

## 五、IPC 通信契约

- **方式**：Named Pipe (`\\.\pipe\Winknow_Control`)
- **ACL**：SYSTEM 完全控制 + Administrators 完全控制 + Everyone 读写（身份由 IpcAuthenticator 校验）
- **消息协议**：Version(uint16) + RequestId(uint32) + Timestamp(int64) + Nonce(16字节) + SenderSid(变长) + MessageType(uint16) + PayloadLength(uint32) + Payload
- **防重放**：时间戳 ±60s + RequestId 单调递增 + Nonce 5 分钟不重复 + DeviceId 匹配

## 六、第1周验收项

- [x] Service 不承担交互式键盘钩子（由 SessionAgent 负责）
- [x] Agent 可在当前用户会话启动（WinExe，由 ControlService 拉起）
- [x] Updater 和 Recovery 有独立入口（独立项目）
- [x] 所有组件运行身份有书面说明（见第三节）
