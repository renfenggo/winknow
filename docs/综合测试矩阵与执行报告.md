## 三、缺陷分级与处置约定

| 等级 | 定义 | 处置 |
|------|------|------|
| P0 | 锁死电脑、蓝屏、系统断网、双进程重启风暴、数据丢失 | 当日修复/回退，暂停放量 |
| P1 | 关键编程软件误拦、更新回滚失败、WMI 不自愈 | 阶段结束前修复或给出规避方案 |
| P2 | 体验问题、非关键误报 | 记录清单，发布评审时决策 |

## 四、本周遗留与环境限制说明

1. **ISCC 编译未执行**：本机未安装 Inno Setup 6，`installer/WinknowSetup.iss` 语法验证待装有 ISCC 的打包机执行（Stage 0 检查表第 3 项）。脚本要点（双服务 sc.exe 安装、.NET 8 Desktop Runtime 注册表+文件系统双检测、策略 onlyifdoesntexist、卸载数据保留提示）已按安装布局约定编写。
2. **签名验证为测试证书模式**：`Sign-Release.ps1 -TestCert` 用自签名证书 + 指纹匹配校验（62 文件通过）；正式发布须组织 EV/OV 证书 + RFC3161 时间戳 + `signtool verify /pa`，测试证书构建不得出机房。
3. **时延/连续运行等实测项**：自动化部分已通过，实测数值由灰度日报回填，最终以《发布决策检查单》发布日复核为准。
