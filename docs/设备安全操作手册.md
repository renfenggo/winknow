> V7.0 第 12 周交付 | 使用对象：机房管理员 | 前置文档：《多品牌BIOS兼容矩阵与部署标准》《部署检查清单》《USB设备矩阵与启动验证方案》《BitLocker剩余风险说明》
> 截图占位说明：文中 `[截图N]` 为现场培训拍照留档位；电子版交付后由各校管理员补齐本机型实拍

## 1. 一次完整部署的流程总览

```
① 断电准备 → ② BIOS 加固（按品牌路径） → ③ 外部启动验证
        → ④ 安装 Winknow → ⑤ 软件自检（B 段清单）
        → ⑥ 设备安全评估 + 人工核验 → ⑦ 导出报告归档
```

## 2. BIOS 加固操作（以联想为例，其他品牌查矩阵第二节）

1. 开机连按 **F1** 进入 BIOS `[截图1：F1 进入后的主菜单]`
2. **Security → Administrator Password**：设置 ≥8 位强密码并记录托管位置 `[截图2：密码设置界面]`
   > 密码记录：写密封信封入保险柜，登记编号（不拍照、不存明文电子档）
3. **Startup → USB Boot → Disabled** `[截图3]`
4. **Startup → Network Boot → Disabled**
5. **Startup → Boot**：内置 HDD/SSD 移到首位，USB/网络项移入 Excluded `[截图4]`
6. **Startup → Boot Menu → Disabled**（关闭 F12 菜单）
7. **Security → Secure Boot → Enabled**（若为 Legacy 机型：先评估 UEFI 切换，参考矩阵）
8. **F10 保存退出**

> 戴尔/惠普/华硕对应路径见《多品牌BIOS兼容矩阵》2.2-2.4 节；Winknow 报告第六节会**自动输出本机品牌**的路径表，可直接对照操作。

## 3. 外部启动验证

按《USB 设备矩阵与启动验证方案》第 3 节执行 USB PE / 移动硬盘 / PXE / Boot Menu 四项尝试，填写 3.5 记录表。全部"启动失败"才算通过 `[截图5：PE 尝试失败的启动画面]`。

## 4. 安装 Winknow

1. 以本地管理员登录，运行 Winknow 安装包（第 13 周交付签名版；当前测试用管理员 PowerShell 安装服务）；
2. 安装完成后重启一次（服务自启动）；
3. `services.msc` 确认 **WinknowControl** 与 **WinknowGuard** 均在运行 `[截图6：服务管理器]`。

## 5. 软件自检（5 分钟）

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 插 U 盘 | 无盘符 `[截图7]` |
| 2 | 插 USB 键盘鼠标 | 输入正常 `[截图8]` |
| 3 | 打开学生 IDE 写个 Hello World | 编译运行正常 |
| 4 | 运行黑名单程序（如手游模拟器） | 被拦截，日志有记录 |
| 5 | 停止 WinknowControl 服务 | 30 秒内被守护自动拉起 `[截图9：守护拉起后的服务状态]` |

## 6. 设备安全评估与人工核验（Winknow 界面）

1. 打开 **Winknow 管理控制台 → 设备安全** 页；
2. 点击 **开始检测**：等待 WMI/注册表采集，出现评分、等级、固件信息、品牌匹配 `[截图10：检测结果页]`；
3. 此时自动项已判定，**人工五项显示"需人工核验"**（这不是缺陷——按设计不得自动视为通过）；
4. 逐项核验：对照报告第六节本机品牌路径，进 BIOS 目视确认每项设置状态；
5. 回到界面：选中一行人工项 → 填管理员姓名（和备注）→ 点 **记为通过 / 记为未通过**；
6. 五项全部记录后，等级从"需人工核验"变为最终评级 `[截图11：核验完成]`；
7. 点击 **导出报告 (MD/CSV)** 保存到归档目录 `[截图12：导出的 Markdown 报告]`。

## 7. 日常复检

| 场景 | 动作 |
|------|------|
| 学期开学 | 设备安全页重新检测 + 抽检 BIOS 七项 + B 段快速自检 |
| **BIOS 更新/主板更换/系统重装** | **强制全流程**：重新 BIOS 加固确认 → 重新检测 → 重新人工核验（旧核验记录已自动失效，界面会红字提示"固件已变化" `[截图13：失效提示]`） |
| 学生报告"突然能用 U 盘了" | 立即按 6 重新检测（重点 secure-boot/usb-boot 状态）+ 查审计日志是否有维护模式记录 |

## 8. 常见问题

| 现象 | 原因 | 处置 |
|------|------|------|
| 评估显示"无法读取（需人工核验）" Secure Boot | Legacy 模式或注册表不可读 | 进 BIOS 目视确认；Legacy 机器优先切 UEFI |
| 等级一直是"需人工核验" | 五项人工项未全部记录 | 完成第 6 节第 4-5 步 |
| 核验后很快又提示失效 | 固件指纹变化（BIOS 更新/主板维修） | 属正常保护，重新核验 |
| USB 键盘在 BIOS 里能用、进系统失灵 | 与 Winknow 无关（HID 不受管控） | 检查 USB 口/Hub 供电，换口测试 |
| 品牌匹配显示"通用机型" | 组装机或代工商串未收录 | 按通用路径核验，备注实际路径反哺矩阵 |

## 附录 A：BIOS 密码遗忘处置

1. 查密码托管（密封信封编号）；
2. 确认遗失后按机型执行清除：多数商用机支持**主板 CMOS 跳线/放电**（惠普部分机型为安全跳线；联想/戴尔部分机型需联系售后）；
3. 清除后所有 BIOS 设置复位：**按第 2 节完整重做加固**，并在 Winknow 重新核验（指纹已变化，系统会自动要求）。

## 附录 B：报告归档要求

- 每台机器每轮核验的 MD+CSV 存放 `\\档案服务器\winknow\{机房}\{机器编号}\`；
- 文件名保持系统默认（含时间戳），不手工改名；
- 纸质签名表（部署清单末尾）扫描件同目录归档。
