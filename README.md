# WinknowV7 - 编程课堂电脑管控系统

Winknow V7.0 是面向 Windows 10/11 编程课堂环境的软件与设备安全管控系统。

## 开发环境

- Windows 10 Pro 22H2+ 或 Windows 11 Pro
- .NET SDK 8.0.400
- Visual Studio 2022（.NET 桌面开发工作负载）

## 常用命令

```powershell
dotnet restore
dotnet build --configuration Release
dotnet test --configuration Release
```

详细需求、技术规范和开发计划位于 `docs/`。
