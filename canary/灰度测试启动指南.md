## 授权系统专项测试（阶段C新增）

### 第八节授权验证演练清单

| 演练项 | 操作步骤 | 预期结果 | 验证方法 |
|--------|----------|----------|----------|
| 拔网线锁定 | 断开网络，等待>5分钟 | 触发锁屏遮罩 | 观察屏幕、检查事件日志 |
| 电话报码解锁 | 教师机生成TOTP→电话告知→学生机验证 | 成功解锁 | 测量解锁耗时、验证时效 |
| 固定码解锁 | 使用预先告知的维护密码 | 成功解锁 | 密码验证、操作日志 |
| 插线自动解锁 | 重新连接网络 | 自动恢复 | 观察自动恢复过程 |
| TOTP时效性验证 | 使用过期TOTP码（>5分钟） | 拒绝解锁 | 验证安全机制 |
| 授权心跳监控 | 观察Collect-CanaryMetrics第九节 | 心跳≥98%、锁定≈0 | 指标达标验证 |

### 授权指标监控重点

# 关键指标核验

- 授权心跳成功率 ≥ 98%

- 解锁操作成功率 = 100%

## 熔断与回退机制

### 熔断触发条件
- **🔴 P0缺陷**：锁死、蓝屏、断网、重启风暴
- **🔴 授权系统故障**：全机断网锁定、无法解锁
- **🔴 性能严重退化**：CPU>80%、内存泄漏
- **🟡 重大兼容问题**：关键软件无法使用

### 回退动作序列
```powershell
# 1. 停止放量
立即停止新机安装

# 2. 问题机回退
.\deploy\Current\Winknow.TrustedUpdater.exe rollback
# 或整包回退：维护模式 → 卸载 → 重装

# 3. 问题采集
.\canary\Collect-CanaryMetrics.ps1 -SinceHours 72
# 事件日志导出 → 缺陷登记 → 复评

# 4. 继续监控
回退机当日仍须出日报
```
